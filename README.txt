Re:Water — прототип для хакатона

ЗАПУСК
Автономная версия: откройте ReWater-demo.html обычным браузером.
Ее можно использовать без интернета, Node.js и установки пакетов.

Для работы с исходниками:
1. Установленный Node.js: откройте папку проекта в терминале.
2. Выполните: node serve.mjs
3. Откройте http://127.0.0.1:4173
Приложение не использует npm-пакеты, API-ключи или внешние шрифты.

РАБОТА С ПРИЛОЖЕНИЕМ
1. Обзор: расчетный баланс и экономия.
2. Потоки: нажмите источник и затем маршрут, чтобы объяснить качество.
3. Сценарии: включите водоподготовку, измените нагрузку и пересчитайте.
4. Экономика: изучите состав экономии и выгрузите отчет.

ЧТО РАБОТАЕТ
Оптимизация распределения воды по объему, качеству и выгоде;
интерактивная карта; проверки каждого маршрута; изменение источников;
импорт источников CSV; тарифы и загрузка; сохранение сценариев в браузере;
расчет простой окупаемости; экспорт текстового отчета.

ГРАНИЦЫ ПРОТОТИПА
Набор «Металлургия» — демонстрационный, а не данные настоящего предприятия.
Требования процессов и водоподготовка — учебные допущения, не нормы.
Рекомендации формирует локальный оптимизатор, живая нейросеть не подключена.
График потребления синтетический; это не обученный прогноз.
Нет подключения к оборудованию, облачной БД и управления установками.
Рабочие данные хранятся в localStorage этого браузера.
Перед применением решений требуется обследование и проверка инженером.
